# My Portfolio Website

This is my first portfolio website project created as an assignment while learning Full Stack Development at Step8Up Bootcamp.

The website is built using HTML and CSS and includes a responsive layout with multiple sections such as:
- Header / Navigation
- Hero Section
- About Me
- Projects
- Contact Form
- Footer

---

## Features

- Responsive design for mobile and desktop
- Sticky navigation bar
- Smooth scrolling navigation
- Project cards with hover effects
- Contact form
- Modern UI design using Flexbox and CSS Grid
- Accessibility improvement using `aria-label`

---

## Technologies Used

- HTML5
- CSS3
